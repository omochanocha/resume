## 概要

フロントエンドを主軸に約4年の実務経験がある。UI/UXの実装だけでなく、Core Web Vitalsを指標としたパフォーマンス改善の提案～実装、運用保守性を考慮したコンポーネント設計を行ってきた。また、チーム全体の生産性向上を意識し、ドキュメント整備や若手メンバーのサポート、技術記事の執筆など組織の技術力底上げにも貢献した。個人開発では、Twitch（動画配信サービス）のフォロー管理アプリをNext.js/React/TypeScript/Auth.jsで開発した。技術記事やSNSでの投稿などから技術をキャッチアップし、自身のGitHubリポジトリで検証した内容をNotionや個人ブログにまとめるなどして管理している。

## 自己PR

### 技術スキル

- **フロントエンド**： LPやアニメーションを伴うサイト、パフォーマンス要件の高いサイトなど、様々な要件のページをFigma等のデザインデータから設計・実装できる。React/TypeScriptは実務・個人開発の双方で使用しており、コンポーネント設計・型設計を実践的に積み上げている
- **バックエンド**： Laravel環境においてテーブル定義からコントローラー実装まで経験、ハッカソンでは将来のデータ増加を見据えたDB設計（非正規化）も実施した

### 開発における志向性・普段意識していること

- **保守・運用を見据えた設計**：将来の変更コストを抑えるため、共通化や抽象化の度合いを適切に判断しながらコードを書くことを意識している。あわせて、命名を丁寧に行うことや実装時の背景・他の選択肢を採用しなかった理由をコメントとして残すことで、後から読む人がコードの意図を追えるようにしている
- **型による安全性の担保**：TypeScriptの `satisfies` 演算子や`Record` 型などを活用し、コンパイル時に網羅性チェックやキーの取りこぼしを検知できる型設計を行うようにしている
- **パフォーマンスへの意識**：Core Web Vitalsをはじめとした指標を起点に、ユーザー体験を損なわない実装を心がけている

### ソフトスキル

- **積極的な越境**：課題を解決するためには自分の領域外のことであっても周囲に助けを求めながら完遂できる。バックエンドの修正や画像の修正の経験があり、職種の垣根を超えてプロジェクトを前に進めることができる
- **チームメンバーへのサポート**： ドキュメント作成や新メンバーの環境構築、ツールの使い方、コーディングに不慣れなメンバーへのサポートを積極的に行い、チームへ貢献した

### 人材紹介サービスのデザイン部署におけるフロントエンド開発

期間：2022年7月~2025年3月

代表プロジェクト概要：複数領域でのデザインリニューアルとページスピードスコア改善

チーム開発：デザイナー1名、フロントエンド1名、ディレクター1名

使用技術・ツール：HTML, CSS(Sass), JavaScript( jQuery ), Figma, Git/Github

#### 【主な取り組みと成果】

■ **Core Web Vitals改善によるUX向上**

○ 状況\
サイトのPV数が減少しており、事業部側の改善施策としてサイトのデザインリニューアルの依頼があった。加えて、優先度は高くないもののページスピードの改善についても要望があった。

○ 判断・成果\
PV数の改善にはページスピードの改善の方がより効果があると考え、サイトリニューアルと並行して取り組んだ。ブラウザの開発者ツールからボトルネックを特定し、事業部側のディレクターと改善策の落としどころを決めた。具体的には、ファーストビューより下にある画像の遅延読み込み・defer属性による不要なJSファイルの遅延読み込み・ファーストビューに不要なJSライブラリの遅延実行を実施し、PSIスコアを最大28点向上させFCPとLCPの改善に貢献した。

■ **運用保守性を高める実装**\
要素が増減したときやテキストが複数行になったとき、アニメーションはどうするかなどのデザインデータに記載のない仕様の部分を事前にすり合わせ、手戻りのない実装になるよう主導した。

■ **積極的な越境**\
画像編集やバックエンド側の処理など専門外の領域でも、課題解決のために必要なことはデザイナーやバックエンドエンジニアの方にレビューをもらいながら対応した。

■ **チーム開発への貢献**\
コードレビューの実施、コードやGitまわりのエラーサポート、自分だけが手順を知っている領域のドキュメント化を行った。

### - Twitch Sort Follow

<https://twitch-sort-follow.omochanocha.dev/>

○ **背景**

Twitchという動画配信サービスを普段利用する中でフォロー管理に不便さを感じていた。フォロー中のチャンネルの並び替えがおすすめ順と視聴者数の降順しかなく、フォロー数が多くなってくると目的のチャンネルを探すのが大変だと感じていた。

○ **判断・成果**

Auth.jsを用いてログイン認証を実装し、認証ユーザーがフォローしているチャンネルを取得。フォロー日順およびアルファベット順（降順/昇順）でソートでき、配信ページへ遷移可能なアプリを作成した。

- Next.js(App Router), React, TypeScript, TailwindCSS, Auth.js, zod, shadcn, ESLint, Prettier, husky, lint-staged, Git/Github, Vercel
